# mini-market

Домашнее задание по НИС «Промышленная веб-разработка на React»: каталог и UI-кит с двумя темами.

## Запуск

Нужен Node.js 22.12+ 

```bash
npm ci
npm run dev
```

Откройте адрес из терминала

```bash
npm run build
npm run typecheck
npm run lint
npm test
npm run preview
```

## Как устроено

- `src/App.tsx` — поиск, категории, корзина и разметка страницы.
- `src/data.ts` — восемь товаров и фильтрация; сервера нет.
- `src/theme.ts`, `src/styled.d.ts`, `src/useTheme.ts` — токены, типизация и выбор темы. Сохранённый выбор важнее системной темы; без него приложение следует системе.
- `src/ui` — Button (primary, outline, ghost, danger; sm, md, lg), Badge, Card, Input, Grid и Skeleton. Служебные пропсы стилей начинаются с `$`.
- `src/ProductCard.tsx` — карточка товара с описанием, ценой и кнопкой добавления в корзину.

Загрузка каталога и добавление в корзину имитируются таймерами, чтобы показать скелетоны и loading. Корзина живёт только до перезагрузки, тема сохраняется в localStorage. Сетка меняется на 2, 3 и 4 колонки при ширине 600, 900 и 1200 px. Для управления доступны клавиатура, заметный фокус, подписи полей и сообщения для скринридера, при reducedmotion внимация отключена.

## styled-components против CSS Modules на моём проекте

В mini-market styled-components позволяет хранить стили кнопки рядом с её пропсами и состоянием загрузки.
Четыре варианта кнопки используют общую разметку, а цвета берутся из типизированной темы.
ThemeProvider передаёт светлую или тёмную палитру всем компонентам, поэтому переключение не требует отдельных классов.
В CSS Modules для вариантов понадобились бы классы, а для тем можно было бы использовать CSS-переменные.
CSS Modules не добавляет библиотеку для вычисления стилей во время работы страницы, поэтому для такого небольшого каталога это тоже подходящий вариант.
В этом задании styled-components удобен для практики темизации и transient props, хотя для статичных стилей CSS Modules был бы проще.
